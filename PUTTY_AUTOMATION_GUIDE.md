# Инструкция по использованию PuTTY Automation

## 🎯 Что это такое

`putty_automation.py` - это скрипт, который использует **PuTTY** для подключения к VPS и автоматизации установки VirtualQubit Turbo Kernel. Это решение проблемы с SSH ключами, когда стандартные Python библиотеки не могут работать с .ppk файлами.

## 📋 Требования

### Обязательные:
- **PuTTY** установлен и добавлен в PATH
- **SSH ключ** `Linux Ubuntu.ppk` в текущей директории
- **VirtualQubit_Shared** папка в текущей директории

### Как проверить PuTTY:
```bash
# Проверка plink (для команд)
plink -help

# Проверка pscp (для передачи файлов)
pscp -help

# Проверка putty (для GUI)
putty -help
```

## 🚀 Как использовать

### Шаг 1: Установка PuTTY
1. Скачайте PuTTY с официального сайта: https://www.chiark.greenend.org.uk/~sgtatham/putty/latest.html
2. Установите полный пакет (включая plink и pscp)
3. Добавьте путь к PuTTY в системную переменную PATH

### Шаг 2: Проверка готовности
```bash
# Проверяем наличие всех файлов
ls -la
# Должны быть видны:
# - putty_automation.py
# - Linux Ubuntu.ppk
# - VirtualQubit_Shared/

# Проверяем PuTTY
python putty_automation.py
# Скрипт сам проверит наличие PuTTY
```

### Шаг 3: Запуск автоматизации
```bash
python putty_automation.py
```

## 📊 Что делает скрипт

### Этап 1: Проверка PuTTY
- Проверяет наличие plink, pscp, putty
- Сообщает о проблемах с установкой

### Этап 2: Установка QEMU
- Обновляет систему
- Устанавливает QEMU и зависимости
- Устанавливает инструменты разработки

### Этап 3: Создание VM среды
- Создает 20GB диск для VM
- Скачивает Ubuntu ISO
- Создает скрипт запуска VM

### Этап 4: Передача файлов
- Передает VirtualQubit_Shared на VPS через pscp
- Передает скрипт запуска VM

### Этап 5: Установка kernel-модулей
- Распаковывает файлы
- Запускает install_kernel_modules.sh
- Устанавливает модули через DKMS

### Этап 6: Системные оптимизации
- Настраивает HugePages (32GB)
- Отключает NUMA balancing
- Устанавливает CPU governor в performance

### Этап 7: Тестирование
- Проверяет загрузку модулей
- Проверяет device nodes
- Проверяет системные настройки

## 🔧 Особенности PuTTY метода

### Преимущества:
- **Работает с .ppk ключами** - не нужно конвертировать ключи
- **Надежное соединение** - PuTTY проверен годами
- **Простота** - не нужно решать проблемы с Python SSH библиотеками
- **Гибкость** - можно использовать все возможности PuTTY

### Как это работает:
1. **plink** - для выполнения команд на VPS
2. **pscp** - для передачи файлов
3. **putty** - для GUI (если нужно)

### Команды, которые использует скрипт:
```bash
# Выполнение команды
plink -ssh root@92.246.131.14 -P 22 -i "Linux Ubuntu.ppk" -batch "apt update"

# Передача файлов
pscp -i "Linux Ubuntu.ppk" -r VirtualQubit_Shared root@92.246.131.14:/root/
```

## 🚨 Возможные проблемы и решения

### Проблема 1: PuTTY не найден
**Решение:**
```bash
# Проверьте установку PuTTY
where plink
where pscp

# Если не найдены - добавьте в PATH
# Или укажите полный путь в скрипте
```

### Проблема 2: Ключ не принимается
**Решение:**
```bash
# Проверьте формат ключа
file "Linux Ubuntu.ppk"

# Попробуйте использовать puttygen для проверки
puttygen "Linux Ubuntu.ppk" -C
```

### Проблема 3: Нет доступа к VPS
**Решение:**
```bash
# Проверьте подключение вручную
plink -ssh root@92.246.131.14 -i "Linux Ubuntu.ppk"

# Проверьте firewall на VPS
# Проверьте SSH сервис
```

### Проблема 4: Ошибки при передаче файлов
**Решение:**
```bash
# Проверьте права на запись
plink -ssh root@92.246.131.14 -i "Linux Ubuntu.ppk" "ls -la /root/"

# Проверьте свободное место
plink -ssh root@92.246.131.14 -i "Linux Ubuntu.ppk" "df -h"
```

## 📞 Альтернативные способы использования

### Способ 1: Ручное подключение через PuTTY
1. Запустите PuTTY
2. Введите IP: 92.246.131.14
3. Выберите SSH, порт 22
4. В Connection → SSH → Auth укажите путь к `Linux Ubuntu.ppk`
5. Сохраните сессию
6. Подключитесь

### Способ 2: Использование plink вручную
```bash
# Выполнение одной команды
plink -ssh root@92.246.131.14 -i "Linux Ubuntu.ppk" "apt update"

# Интерактивная сессия
plink -ssh root@92.246.131.14 -i "Linux Ubuntu.ppk"
```

### Способ 3: Передача файлов через pscp
```bash
# Передача папки
pscp -i "Linux Ubuntu.ppk" -r VirtualQubit_Shared root@92.246.131.14:/root/

# Передача одного файла
pscp -i "Linux Ubuntu.ppk" setup.py root@92.246.131.14:/root/
```

## 📊 Сравнение методов

| Метод | Плюсы | Минусы |
|-------|-------|--------|
| **Python + paramiko** | Автоматизация, логирование | Проблемы с .ppk ключами |
| **PuTTY automation** | Работает с .ppk, надежно | Требует установки PuTTY |
| **Ручной** | Полный контроль | Долго, много ручной работы |
