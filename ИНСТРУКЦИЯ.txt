⚡ Шаг 1 — установить QEMU

На Ubuntu / Debian:

sudo apt update
sudo apt install qemu-system-x86 qemu-utils -y

На CentOS / Alma / Rocky:

sudo dnf install qemu-kvm qemu-img -y
📦 Шаг 2 — создать диск VM

Например 20 GB:

qemu-img create -f qcow2 vm.qcow2 20G
💿 Шаг 3 — скачать ISO Linux

Например Ubuntu Server:

wget https://releases.ubuntu.com/24.04/ubuntu-24.04-live-server-amd64.iso

(можешь любой дистрибутив)

🚀 Шаг 4 — запустить VM (без KVM, чистый QEMU)

Это работает даже на самом ограниченном VPS:

qemu-system-x86_64 \
  -m 2048 \
  -smp 2 \
  -drive file=vm.qcow2,format=qcow2 \
  -cdrom ubuntu-24.04-live-server-amd64.iso \
  -boot d \
  -net nic -net user \
  -nographic

Что происходит:

VM запускается в терминале

установка через текстовый интерфейс

сеть через user-mode NAT

🌐 Доступ по SSH в VM

Добавь port forward:

-net user,hostfwd=tcp::2222-:22

Полная команда:

qemu-system-x86_64 \
  -m 2048 \
  -smp 2 \
  -drive file=vm.qcow2,format=qcow2 \
  -cdrom ubuntu-24.04-live-server-amd64.iso \
  -boot d \
  -net nic \
  -net user,hostfwd=tcp::2222-:22 \
  -nographic

Потом:

ssh user@localhost -p 2222

Запуск без ISO:

qemu-system-x86_64 \
  -m 2048 \
  -smp 2 \
  -drive file=vm.qcow2,format=qcow2 \
  -net nic \
  -net user,hostfwd=tcp::2222-:22 \

🚀 Если VPS поддерживает KVM (намного быстрее)

Проверь:

egrep -c '(vmx|svm)' /proc/cpuinfo

Если > 0 — попробуй:

qemu-system-x86_64 -enable-kvm ...

Или:

ls /dev/kvm
🧪 Pro режим — kernel hacking lab

Можно:

запускать своё ядро через -kernel

подключать initramfs

делать snapshot

тестировать патчи

запускать fuzzing

Пример:

qemu-system-x86_64 \
  -kernel bzImage \
  -append "console=ttyS0" \
  -nographic

Так делают разработчики ядра Linux.
