# Список созданных файлов

## 🎯 Основные скрипты автоматизации

### `virtualqubit_automation.py` (34KB)
**Главный скрипт полной автоматизации**
- Полностью автоматизирует настройку VirtualQubit Turbo Kernel
- Подключается к VPS по SSH
- Устанавливает QEMU и зависимости
- Создает и настраивает виртуальную машину
- Устанавливает kernel-модули VirtualQubit и Turbo Scheduler
- Настраивает системные оптимизации
- Тестирует установку и генерирует отчеты

### `setup.py` (6KB)
**Скрипт проверки и установки зависимостей**
- Проверяет версию Python (требуется 3.8+)
- Проверяет наличие всех необходимых файлов
- Проверяет наличие SSH ключа
- Проверяет и устанавливает Python зависимости
- Создает ярлыки для запуска
- Выводит итоговую информацию о готовности системы

### `ssh_setup.py` (7KB)
**Скрипт настройки SSH ключей**
- Проверяет формат SSH ключей (.ppk, OpenSSH)
- Конвертирует .ppk ключи в OpenSSH формат
- Тестирует SSH подключение
- Настраивает SSH агент
- Предлагает альтернативные варианты подключения

## 🎯 Как использовать

### Полная автоматизация (рекомендуется)
```bash
# 1. Настройка SSH ключей
python ssh_setup.py

# 2. Проверка готовности системы
python setup.py

# 3. Запуск автоматизации
python virtualqubit_automation.py
```

### Пошаговая ручная настройка
```bash
# 1. Подключение к VPS
ssh -i "Linux Ubuntu.ppk" root@92.246.131.14

# 2. Установка QEMU
./setup_vps.sh

# 3. Запуск VM
./start_vm.sh

# 4. Установка модулей
./install_kernel_modules.sh
```
